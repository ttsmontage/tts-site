# TTS — site vitrine

Site vitrine statique en HTML/CSS/JavaScript, sans dépendance ni abonnement.

## Prévisualiser
Ouvrir `index.html` dans un navigateur. Une connexion Internet est nécessaire pour charger les polices Google Fonts ; le site reste lisible sans elles.

## Publier gratuitement avec GitHub Pages
1. Dans **Settings → Pages**, choisir **Deploy from a branch**.
2. Sélectionner la branche `main` et le dossier `/ (root)), puis enregistrer.
3. GitHub Pages affichera l'adresse publique du site.

## À personnaliser avant publication
- Remplacer les coordonnées à venir dans la section Contact.
- Ajouter les vidéos du portfolio et vérifier les autorisations de diffusion.
- Ajouter éventuellement les liens vers les réseaux sociaux.
- Confirmer les textes, tarifs et conditions commerciales avant de les rendre publics.

Les aperçus graphiques du portfolio sont des placeholders et ne prétendent pas être des réalisations clients.
